Network-panel audit (plan.md §8, constraint 3)

Inspect the service worker's network activity (chrome://extensions → TrueOrigin → “Inspect views: service worker” → Network tab). What appears depends on two caches — the 24 h trust-list cache and the worker's in-memory verdict cache, which lives until Chrome stops the idle worker (~30 s):

  • Cold worker, cold trust cache (first run in 24 h): five trust-list fetches (verify.contentauthenticity.org ×3, raw.githubusercontent.com ×2) plus the cai-manifests.adobe.com fetch triggered by cloud.jpg.
  • Cold worker, warm trust cache (within 24 h): only the cloud.jpg manifest fetch.
  • Warm worker (reload within ~30 s of the last analysis): possibly no requests at all — the task-5.2 verdict cache recognizes the image bytes and skips re-analysis, including the manifest fetch.

In every tier, nothing else — no media bytes, no page URLs.
